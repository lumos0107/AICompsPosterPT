# 새 그래프 점검 결과 (2026-11-10)

코드는 같은 폴더의 `build_graph.py`, `check_grade.py`, `check_grade2.py`, `check_grade3.py`, `check_final.py`이고 원 출력은 `그래프점검.out`, `입체점검.out`, `입체점검2.out`이다. 자료 목록은 `자료정리표.md`, 영상 판정은 `입체판정.csv`.

5월 사본에 같은 코드를 돌려 지난 값을 모두 재현했다(연결 95.80·97.00·98.12%, 소구역 99.04·98.75·99.61·100.00%, 겹침 0.77%, 민감도 0.62~0.85%).

## 1. 주 연결 요소 비율 (제주 전체 그래프)

처리 순서는 `check_connect.py`와 같다(전체 도로로 노드와 1m 보정을 만든 뒤 제외). 섬은 폭을 빼기 전 전체 그래프에서 판별해 간선 표시로 들고 갔다.

| 경우 | 5월 사본 도로 | 5월 사본 비율 | 새 자료 도로 | 새 자료 비율 |
|---|---:|---:|---:|---:|
| 전체 | 14,424.3km | 95.80% | 14,578.9km | 95.47% |
| 섬 제외 | 14,246.7km | 97.00% | 14,396.9km | 96.68% |
| 폭 3m 미만 제외 | 10,968.9km | 98.12% | 11,151.6km | 97.84% |
| 둘 다 제외 | 10,835.9km | 99.33% | 11,014.6km | 99.05% |

8장 기준(섬 제외 본섬, 95% 이상)은 새 자료 96.68%, 실험에 쓸 조건인 둘 다 제외는 99.05%로 넘는다. 섬 5곳은 두 자료 모두 한 조각씩 판별됐다.

폭을 뺀 뒤 5km 규칙으로 섬을 다시 판별했다면 둘 다 제외 값은 새 자료 99.01%, 5월 사본 99.24%다. 폭 제외로 섬이 5km 이하로 쪼개진 조각이 새 자료 3개 4.4km, 5월 사본 4개 9.4km 있어서다. 표는 전체 그래프에서 판별한 값이다.

폭 제외 뒤 연결 요소 수는 5월 240개, 새 자료 686개로 늘었다. 폭 분포는 거의 같고(폭 3m 미만 선 12.6%, 13.0%), 주 요소 밖 조각은 새 자료 둘 다 제외 기준 678개 104.3km로 대부분 1km 미만이고 5km 이상은 없다. 늘어난 원인은 확인하지 못했다.

## 3. 겹친 길 비율 (제주시 시험구역, 11/9 진단과 같은 정의)

방향 차이 12도 미만, 옆 거리 1~12m, 노드를 공유하지 않는 쌍. 길이 3m 미만 조각 제외. 15m 분할은 이 측정에만 썼고 그래프를 재표집하지 않았다.

| 방식 | 5월 전체 | 새 전체 | 5월 폭 제외 | 새 폭 제외 |
|---|---:|---:|---:|---:|
| 간선 15m 분할 (s4 방식) | 0.77% | 0.76% | 0.62% | 0.59% |
| 선 단위 10m 분할 (s7 방식) | 0.85% | 0.85% | 0.66% | 0.64% |
| 선 단위 15m | 0.76% | 0.76% | 0.61% | 0.59% |
| 선 단위 20m | 0.66% | 0.64% | 0.54% | 0.51% |
| 선 단위 30m | 0.62% | 0.63% | 0.50% | 0.50% |

8장 기준 1% 이하를 모든 분할 간격에서 넘는다. 옆 거리를 30m로 넓히면 간선 15m 분할 기준 새 자료 10.55%, 폭 제외 9.56%이고(5월 10.14%, 9.21%), 11/9 진단에서처럼 이 구간은 1% 기준 대상이 아니다.

## 4. 입체 구간 (영상 판정은 Claude 단독, 영상 촬영 시기는 미확인)

교차로 면의 입체교차점 9곳, 입체교차부 1곳, 인터체인지 1곳, 경계 3m 안쪽에 분기 노드가 있는 교량 23곳, 표본 R13 하나를 영상과 대조했다. 육교 면 4개 안에는 도로 노드가 없다. 도로선은 사이트에 올리지 않고 캡처한 영상에 내 PC에서 겹쳐 그렸다.

| 대상 | 잘못된 연결 | 폭 제외로 해결 | 실제 교차·문제 없음 | 불명확 |
|---|---:|---:|---:|---:|
| 입체교차부 1 | 1 | | | |
| 입체교차점 9 | 1 (광령4, B0170과 같은 곳) | | 7 | 1 |
| 인터체인지 1 | | | | 1 (축척 부족) |
| 교량 23 | 8 | 5 | 9 | 1 |
| R13 | 1 | | | |

잘못된 연결은 서로 다른 위치 기준 10곳이다: 공항지하차도, R13, 제6광령교(광령4), 제2태흥교, 동명교, 제4광령교, 해안육교, 우남육교, 색달육교, 이름 없는 다리 B1295. (처음 11곳으로 적었으나 죽성육교는 간선 확인 결과 끊을 연결이 없어 11/10 정정. `신호검증_결과.md` 2장)

면 안 연결을 끊는 계획서의 규칙에는 문제가 둘 있다.

1. 교량 면 안 분기 23곳 중 9곳은 실제 교차이거나 문제가 없다(복개 구간 위 시내 교차로, 다리 끝 삼거리). 자동으로 끊으면 이곳이 잘못 끊긴다.
2. R13은 가장 가까운 교량·육교 면에서 218m 떨어져 있어 면 규칙으로 잡히지 않는다. R13의 횡단 도로는 노드 근처에서 꺾여 직진 쌍 검사로도 잡히지 않았다.

면 없는 곳의 규모: 차수 4 직진 교차이면서 넓은 도로(폭 15m 이상 또는 분리대) 축이 있는 노드 1,392개 중 1,199개가 어떤 면에도 없다. 시드 20261110으로 20곳을 뽑아 영상으로 보니 입체 의심 2곳, 불명확 1곳, 평면 17곳이다. 표본이 작아 전체 비율로 옮기지 않는다. 소구역에서 차수 4 이상이고 넓은 도로 간선이 2개 이상인 노드는 제주시 시험구역 542개, 서귀포시내 115개다(R13 포함 조건).

연결 비율은 잘못된 연결까지 연결로 세는 값이다.

## 5. 계단
