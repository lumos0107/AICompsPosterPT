# 길동무 논문 인수인계 2026-11-10 세 번째 (신호 위치 기준 미달, 사용자 답 대기)

> 먼저 이 문서, 다음에 `실험/새그래프_1110/신호검증_결과.md`와 `그래프점검_결과.md`. 자료 전체는 `2026-11-10-handoff.md`와 `데이터/수집계획.md`.

## 1. 사용자 지시 (11/10, 원문 요지)

1. ITS 키는 없다고 가정한다. 나중에 키가 오면 교체할지 **그때 사용자에게 묻는다.**
2. 입체 연결·야간 선호(뺌)·정밀도로지도(받지 않음)·계단(1m 이상 간선 제외)은 제안대로.
3. 1:1,000은 독립 검증용. 신호 위치는 신호기현황 단일로 제외 830건을 브이월드로 변환.
4. 8장 신호 기준은 신호기현황 기준으로 값을 제안하고 **실험 전에 사용자 확인.**
5. 주소 변환 결과가 기준에 못 미치면 **혼자 바꾸지 말고 묻는다.** 1:1,000을 위치 자료로 쓰고 실험 범위를 도엽으로 좁히는 안을 같이 가져온다.
6. 영상 확인은 예비 경로뿐 아니라 **본 실험에 실제로 쓰인 경로의 교차까지** 같은 방식으로 하고, 확인 수와 판정 못 한 곳을 기록한다.
7. 원본 지도 파일은 외부 서비스나 GPT 검토에 올리지 않는다. 영상 대조 때 도로선은 PC에서 겹쳐 그린다.
8. 마감일은 아직 모른다.

## 2. 지금 상태

- 끝남: 연결 요소 증가 원인(성산읍 폭 값 변화, 그래프 수정 없음), 입체 10곳 끊기(죽성육교는 끊을 연결이 없어 11곳에서 정정), 계단 제외, 고도 격자, 화장실 주소 변환, 편의시설 정리, 신호 830건 변환, 1:1,000 대조.
- 최종 그래프: `실험/새그래프_1110/그래프_최종.npz`, 주 요소 비율 99.05%, 10,908.8km.
- **멈춘 곳: 신호 위치.** 변환 성공 97.2%지만 30m 안 차수 3+ 노드 51.1%(기준 80%). 도로 위 무작위 점 54.8%보다 낮다. 사용자 답을 받기 전에는 신호 판정 위치·반경을 정하지 않고, 코드 수정·실험으로 넘어가지 않는다.

## 3. 사용자에게 물은 것 (답 대기)

1. 신호 위치 자료: 안 1(1:1,000 위치, 실험 범위 도엽으로) / 안 1-1(제주 도심만) / 그 밖의 지시.
2. 안 1이면 반경 제안 20m 수용 여부.
3. 8장 값 제안: 신호 부착 80% 유지, 서귀포 횡단보도 50%, 위치 타당성 70%(둘 다 측정 뒤 정한 값).

## 4. 다음 할 일 (답을 받은 뒤)

코드 수정(비용 단위, 귀환 구간 선호, 재사용 판정, 시설 항) -> 예비 경로 -> 3장 나 점검(경사 구간 50·100·200m, 세 선호 값, 두 시 차이) -> 경로 교차 영상 확인 -> 8장 최종 판단 -> 사용자 확인 -> 본 실험 -> 본 실험 경로 교차 영상 확인 -> 초안 고치기. 경사 계산 때 교량 양 끝 보간을 넣는다.

## 5. 확인 못 한 것

1. 성산읍을 다시 조사했다는 것은 추정이다. 영상으로 m 단위 폭은 재지 못했다.
2. 표고점 0 이하 112개 중 등고선과 5m 넘게 다른 66개를 하나씩 보지 않았다.
3. 서귀포시내 변환 위치가 1:1,000에서 100m 넘게 떨어진 20.9%의 원인(2013·2017년 도엽 시점 차이로 추정, 미확인).
4. 동광나들목, 동광1교차로, 직사교의 입체 판정.
5. 서귀포시 화장실 주소 변환의 위치 정확도는 재지 않았다.
6. 초안 출발점 4곳이 도엽 범위 안인지(안 1 채택 때 확인).
