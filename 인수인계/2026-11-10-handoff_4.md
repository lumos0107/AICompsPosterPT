# 길동무 논문 인수인계 2026-11-10 네 번째 (제주 도심 실험 범위, 반경·출발점 답 대기)

> 먼저 이 문서, 다음에 `실험/도심실험_1110/도심실험_결과.md`. 앞 단계는 `2026-11-10-handoff_3.md`, `실험/새그래프_1110/신호검증_결과.md`, `그래프점검_결과.md`. 자료 전체는 `2026-11-10-handoff.md`, `데이터/수집계획.md`(8장 표와 10장 7항 갱신).

## 1. 사용자 결정 (11/10, 원문 요지)

1. 1:1,000을 신호 위치 자료로 쓰고 제주 도심 95장으로만 실험한다. 반경은 20m.
2. 서귀포시내를 뺀 이유는 변환 위치 100m 안에 1:1,000 장비가 없는 비율(서귀포시내 20.9%, 제주 도심 0.8%)로 기록한다.
3. 신호기현황 변환 위치는 1:1,000 누락 점검으로만, 합격선 없이 값만 기록한다.
4. 실험 그래프는 도엽 범위로 잘라 경로가 밖으로 나가지 않게 한다(밖은 신호가 없는 것처럼 보여 신호 회피 경로가 밖으로 쏠림). 자른 그래프의 주 연결 요소 비율을 다시 잰다.
5. 초안 출발점 4곳이 범위 안인지 보고, 밖이면 대체 후보를 가져온다. **출발점은 확정 전에 사용자 확인.**
6. 20m에서 안 붙고 30m에서만 붙는 묶음을 영상으로 보고 큰 교차로가 빠지는지 기록한다. **여럿 빠지면 반경을 다시 묻는다.**
7. 8장 신호 기준은 교차로 부착 80%만 합격선, 무작위 도로 점 값을 옆에 적는다. 서귀포 횡단보도 기준은 뺀다. 50%·70%는 측정값으로만 기록.
8. 앞 지시 유지: 원본 지도 파일은 외부 서비스·GPT 검토에 올리지 않는다. ITS 키가 오면 교체 여부를 그때 묻는다. 마감일 미정.

## 2. 지금 상태

- 끝남: 1~4, 6, 7번. 자른 그래프 `실험/도심실험_1110/그래프_도심.npz`(main), 주 요소 비율 99.60%. 20m 묶음 부착 81.2%(무작위 점 52.8%, 무작위 이동 묶음 70.6%).
- **멈춘 곳:** 20m에서 큰 교차로 9곳이 빠져 반경을 다시 물음. 탑동이 도엽 밖(4m)이라 출발점도 물음.
- 정정: `check_signals.py`의 무작위 도로 점이 교차로 쪽으로 치우쳐 있었다(30m 54.8% -> 48.0%). 결론은 같음.

## 3. 사용자에게 물은 것 (답 대기)

1. 반경: 20m 유지 / 25m / 30m / 20m + 안 붙은 묶음만 30m 안 가장 가까운 노드 하나(제안).
2. 출발점: 탑동은 가장 가까운 노드(도엽 안, 42.6m)로 그대로 두는 안을 제안하고, 대체 후보는 동문로터리·제주종합경기장·신산공원(좌표는 대략). 나머지 세 곳은 범위 안.

## 4. 다음 할 일 (답을 받은 뒤)

신호 노드 확정 -> 코드 수정(비용 단위, 귀환 구간 선호, 재사용 판정, 시설 항, 범위 밖 방향 안내점 제외, 교량 양 끝 고도 보간) -> 예비 경로 -> 3장 나 점검(경사 50·100·200m, 세 선호 값; 두 시 차이는 서귀포가 빠져 해당 없음, 사용자에게 알릴 것) -> 경로 교차 영상 확인 -> 8장 최종 판단 -> 사용자 확인 -> 본 실험 -> 본 실험 경로 교차 영상 확인(확인 수·판정 못 한 곳) -> 초안 고치기.

## 5. 확인 못 한 것

1. 20~30m 묶음 27곳의 큰·중간·작은 교차로 구분은 Claude 단독 영상 판정.
2. 변환 위치가 1:1,000에서 50m 넘게 떨어진 7건이 1:1,000 누락인지 변환 오류인지.
3. 30m에도 안 붙는 묶음 20곳(신호등 38, 제어기 6)의 성격(단일로·보행 신호로 추정, 미확인).
4. 대체 출발점 좌표는 지도에서 고른 대략 위치다.
5. 편의시설·고도는 제주 전체로 만들었으므로 실험 범위 안에 몇 건 있는지 아직 세지 않았다.
