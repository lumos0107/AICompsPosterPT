## 4. 확인한 사실

### 가. 소구역 점검 (5월 사본, `실험/소구역점검_1109/소구역점검_결과.md`)

1. 연결: 주 연결 요소 비율은 제주시 시험구역 99.04%, 서귀포시내 98.75%, 전체 95.80%, 섬 5곳(177.6km) 제외 97.00%. 1m 보정 규칙을 유지한다.
2. 독립 보행로: 인도 선의 다수가 닫힌 테두리라 286.4km는 실제 약 174km다. 표본 40곳 중 독립 산책로 0곳, 1km 이상 묶음 전수 28개 중 3개(환산 1.77km, 2개는 추정). 그래프에서 제외를 유지한다.
3. 보행 가능 여부: 폭 3m 미만 12곳 중 길이 보인 곳 1곳, 길 안 보임 7곳, 가림 4곳. 폭 3m 이상 27곳은 달릴 수 있음 24곳, 주의 3곳.
4. 폭 3m 미만을 빼면(5월 자료) 전체 3,455km(24.0%) 감소, 주 연결 요소 비율 98.12%, 소구역 감소는 제주시 8.3%, 서귀포시내 9.8%.
5. 대학·리조트·골프장 안 도로 일부가 도로중심선에 없는 것으로 보인다. 도로경계의 부지안도로와 관련 있는지는 미확인이다. 출발점을 고를 때 이런 곳을 피한다.

### 나. 설명서 전체 확인 (계획서 4장 가 끝부분)

1. 1:5,000 포장 코드는 RDQ005 비포장, RDQ006 포장, RDQ000 미분류다. `소구역점검_1109/make_samples.py`는 미분류(5월 128선)를 포장으로 셌다. 새 코드에서는 구분한다.
2. 계단(C0390000)은 STRU SRD001만 제외 규칙에 쓴다. SRD002는 스탠드(관람석)다.
3. 1:1,000 전용 항목: 차단기(C0503375)의 구분 신호등제어기·가로등제어기, 신호등(C0493376)의 용도 보행용·차량용, 조명(C0220000)의 가로등·방범등, 횡단보도(A0043325).
4. 입체교차부에 구분(고가·지하)과 보도 유무(SDWK), 교량에 보도교(BRK002), 도로중심선에 일방통행(ONSD)과 분리대 유무(DVYN)가 있다.
5. 1:1,000 SHP의 항목명은 한글(용도, 구분, UFID 등)이다.
6. 도곽선에 제작년도·촬영년도 칸이 있으나 제주 379개 도엽 모두 빈칸이다. FMTA는 별도 제작정보 표의 일련번호라 날짜를 알 수 없다. 1:5,000 기준일은 신청한 제작년도 2024와 파일 생성 2025-10-22로 적는다. 1:1,000은 도엽별 xml에 촬영·조사·제작년도가 있다.

### 다. 자료 대조

1. 브이월드 전국본의 제주 범위 상자에는 419,768건(001에 419,746건, 002에 22건)이 있고, 국토정보맵 파일의 UFID 419,658건이 전부 포함된다. UFID 기준으로 같은 자료다. 처음 계획한 길이·연결·겹침 비교와 영상 표본은 UFID가 일치해 하지 않았고, 선 형상을 직접 비교한 것은 아니다. 차이 110건은 상자에 걸린 주변 자료로 보이지만 확인하지 않았다.

3. 브이월드 화면의 갱신일은 자료 시점이 아니다(입체교차부 갱신일 2026-09-21, 파일 안 수정일 2025-09-09).

   - 정할 것: 1:1,000의 역할(2장), 신호등제어기와 신호등을 교차로 단위로 묶는 규칙(제어기만 쓸지 합칠지, 계획서 6장은 '30m로 묶어'까지만 적혀 있다), 도엽 경계의 중복 처리(계획서 6장, 아직 측정 안 함).
   - 서귀포시내 NGI 71장은 좌표와 속성을 잇는 코드가 없다. `check_1000_ngi.py`는 NDA 속성 건수만, `check_ngi.py`는 형태 개수만 센다. 파서를 새로 만들어야 한다. 제주시와의 시점 차이는 한계로 적는다.
5. 서귀포시 화장실 391건 주소 변환(브이월드 키, 공개 시설 주소만 전송). 일부는 도로명 칸에 지번 형식이 있어 도로명과 지번을 모두 시도한다.

## 6. 사이트 사용법 (이번에 확인)

1. 국토정보맵 `map.ngii.go.kr`: 수치지도 바로가기 → 간편지도 검색 → 영역 → 사각형으로 드래그 → 수치지도 → 수치지형도Ver2.0 → 축척 칸 1:1,000 → 전체 다운로드. 행정구역 선택은 목록이 500건에서 잘린다.
2. 수치지도는 한 번에 100장 미만만 받을 수 있다. 이 제한을 피하는 호출은 하지 않았다. 더 많이 필요하면 범위를 나눠 사용자와 상의하거나 오프라인 신청을 쓴다.
3. 다운로드 전에 신청서가 뜨고 사용자 준수사항 동의가 있다. 동의는 사용자가 건별로 말한 뒤에만 눌렀다. 준수사항에 측량성과 국외 반출 금지가 있어, 원본 지도 파일을 외부 서비스나 GPT 검토에 올리지 않기로 사용자에게 말했다.
4. 연속수치지형도: [도 영역] 체크 → 다운로드 → 마이페이지 신청내역 → 자료선택에서 형식 SHP, 제작년도, 폴더 체크 → 신청등록 → 다운로드.
5. Playwright로 받을 때: 로그인은 사용자가 창에서 직접 한다. `ctx.grantPermissions(['local-network-access'], {origin})`을 `map.ngii.go.kr`, `nlippd.ngii.go.kr`에 준다. 다운로드 창에서 전체 다운로드 → 전송시작. 임시 파일 `.irx`가 없어져야 끝난 것이다.
6. 도엽 조회 `/ms/map/suchiQuery.do`는 지도 한 장 안에 드는 범위만 찾는다. 넓은 범위는 0건에 가깝게 나오므로 600m 간격의 1m 상자로 훑는다.
7. 영상 확인: `NlipMap.do`에서 `fnBaseLayer('TMS Layer_2013')`, 전역 `map`(OpenLayers, EPSG:5179). 줌 11에는 이 지역 영상이 없어 10이나 12를 쓴다.
8. 제주 ITS 신청: `open_apiView.do` 페이지 아래쪽 'ITS OPEN API 신청' 버튼, 교통시설물정보만 체크, 첨부는 신분증(주민번호 뒷자리 제거)도 가능.
9. 브이월드 다운로드 검색 `dtmk_ntads_s001.do?svcCde=MK&searchKeyword=`. 신호, 가로등, 화장실, 어린이보호구역은 0건(같은 방식으로 도로중심선 2건 확인). 보행자전용도로·공공보행통로·보행자우선도로(현황), 등산로(1:25,000)가 있으나 제주 수록 여부를 확인하지 않았고 받지 않았다.

## 7. 주의

1. 받은 파일은 자료마다 새 폴더에 두고, 스크립트는 다른 폴더에 두고, 파이썬은 `-I`로 실행했다.
2. `소구역점검_1109/표본추출.out`의 칸별 km는 3m 점 개수로 낸 값이라 부풀려져 있다. 비율은 `연결점검.out`의 실제 길이를 쓴다.
3. 영상 판정은 Claude가 혼자 했고 영상 촬영 시기는 확인하지 못했다.
4. 검색이 0건이면 있는 자료가 잡히는지 먼저 본다. 이번에도 포털 검색과 넓은 범위 도엽 조회가 처음에는 실패한 검색이었다.
5. 서귀포시내 1:1,000은 도엽의 80% 이상이 2013·2017년이고 제주시내는 2025년이다.
6. 설명서처럼 자료의 기준이 되는 문서는 낱말 검색으로 끝내지 않고 끝까지 읽는다. 차단기 항목의 신호등제어기를 그렇게 찾았다.
