# 데이터 수집 계획 2판 (2026-11-09, 사용자 확인 대기)

대상은 제주특별자치도. 6장의 자료 품질 기준을 넘지 못하면 경로 실험 전에 다른 도시(1순위 대전)로 옮긴다.
겹침 수치는 5월에 받아 둔 같은 자료를 제주 범위로 잘라 잰 값이다. 측정 코드는 `../실험/데이터진단_1109/수집계획용/`.
상태 표기: 받음 / 받을 수 있음(로그인 없음) / 로그인 / 키 필요 / 확인 필요.

## 1. 기본 구조

겹침을 막기 위해 선 자료를 합치지 않는다. 뼈대는 도로중심선 하나이고, 나머지는 속성으로만 붙이거나 그래프 밖에서 검증에만 쓴다.

```
[그래프 뼈대]  도로중심선 하나
      ▲  선을 더하지 않고 속성으로만 붙임
[구간 속성]  인도 · 교량 · 터널 · 계단 · 도로분리대 · 고도 · 녹지 · 해안 거리
[지점 속성]  신호 교차로 · 횡단보도 · 화장실 · 편의점 · 공원

[그래프 밖]  러닝 코스 · 정밀도로지도 · 빼 둔 표고점 → 검증에만 사용
```

## 5. 겹침 외의 문제

1. 지역 불균형: 일반 횡단보도 전역 자료는 서귀포시만 있고, 1:1,000은 시내 밖 포함률이 낮다. 횡단 선호는 섬 전체에 쓸 수 있는 '신호 교차로'로 정의한다(제안). 횡단보도까지 쓰려면 자료가 있는 범위 안에서만 출발점을 고른다.
2. 신호제어기 자료: 좌표계와 실제 건수를 응답으로 확인해야 한다. 안 되면 신호기현황 주소를 변환하는데, 번지 주소는 필지 중심이라 교차로에서 벗어날 수 있다.
3. 1:1,000 수록 여부: 규격에는 항목이 있으나 제주 도엽의 실제 수록은 표본으로 확인해야 한다. NGI 형식은 GDAL이 읽지 못해 직접 해석하거나 DXF판을 쓴다.
4. 외부 전송: 주소 변환 API에는 공개 시설 주소만 보낸다.
5. 러닝 코스 자료: 이용자가 올린 코스이고 2021년까지이며, 논문 사용 조건을 확인해야 한다.
6. 도로 등급: 82.5%가 '미분류'라 등급 대신 차로수와 도로 폭을 쓴다.
7. 시점 차이: 2020(어린이보호구역), 2021(녹지), 2022(신호기), 2025~26(그 외). 자료별 기준일을 기록하고 논문 한계로 적는다.
8. 공원은 점 1개로만 제공되어 넓은 공원은 입구 위치가 아니다.

## 8. 사용자 확인이 필요한 것

1. 도로에서 떨어진 보행로를 1차에서 제외 (해안·공원 산책로 일부가 빠질 수 있음)
2. 횡단 선호를 '신호 교차로'로 정의
3. 새 선호 항목은 녹지 하나만 추가
4. 논문 마감일 (정보공개청구와 1:1,000 전체 수집의 여유 판단)
