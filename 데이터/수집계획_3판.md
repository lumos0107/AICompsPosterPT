# 데이터 수집 계획 3판 (2026-11-09)

대상은 제주특별자치도. 전체 수집 전에 소구역에서 먼저 점검하고, 8장의 자료 품질 기준에 따라 보정, 범위 제한, 도시 이동을 정한다.
겹침 수치는 5월에 받아 둔 같은 자료를 제주 범위로 잘라 잰 값이며, 최종 수치는 새 자료로 다시 잰다. 측정 코드는 `../실험/데이터진단_1109/수집계획용/`.
GPT 평가(`GPT평가_수집계획2판_1109.md`, 2판 기준) 중 데이터 없이 성립하는 지적과 실측으로 확인한 지적만 반영했다. 2판은 `수집계획_2판.md`.
상태 표기: 받음 / 받을 수 있음(로그인 없음) / 로그인 / 키 필요 / 확인 필요.

## 1. 기본 구조

겹침을 막기 위해 선 자료를 합치지 않는다. 뼈대는 도로중심선 하나이고, 나머지는 속성으로만 붙이거나 그래프 밖에서 검증에만 쓴다.

```
[그래프 뼈대]  도로중심선 하나
      ▲  선을 더하지 않고 속성으로만 붙임
[구간 속성]  인도 · 교량 · 터널 · 계단 · 도로분리대 · 고도
[지점 속성]  신호 교차로 · 화장실 · 편의점 · 공원

[그래프 밖]  정밀도로지도 · 빼 둔 표고점 : 검증에만 사용
```

## 2. 먼저 고정할 것: 선호 정의

| 선호 | 비용 단위 (제안) | 논문 지표 | 쓰는 자료 |
|---|---|---|---|
| 경사 | 구간 길이에 비례 | 거리 가중 평균 경사 | 고도 |
| 신호 교차로 | 통과 1회당 | 신호 교차로 경유 횟수 (km당) | 신호 교차로 |
| 편의시설 | 구간 길이에 비례 | 가장 가까운 시설까지의 평균 거리 (최대 500m) | 화장실, 편의점, 공원 |

1. 나가는 구간과 돌아오는 구간의 비용 단위를 같게 한다. 지금 초안은 수식 (3)이 단계당, 수식 (4)가 길이 곱이다.
2. 같은 경로를 다른 간격으로 나눠도 비용이 크게 달라지지 않는지 확인한다.
3. 논문에서는 신호 교차로 경유 횟수만 주장하고, 안전 개선이나 정지 감소는 주장하지 않는다.
4. 귀환 구간 선호, 재사용 판정, 시설 항의 코드 수정은 재실험 전에 별도로 한다.

경사 검증: 표고점 일부를 구역 단위로 나눠(공간 분리) 보간에 쓰지 않고 오차를 잰다. 구간 길이 50·100·200m에서 경사 선호의 효과가 같은 방향인지 확인한다.

## 7. 겹침 외의 문제

1. 지역 불균형: 일반 횡단보도 전역 자료는 서귀포시만 있어, 주 실험에는 두 시에 같은 정의를 쓸 수 있는 신호 교차로를 쓴다. 차이의 규모는 소구역에서 확인한다.
2. 신호제어기 자료: 좌표계와 실제 건수를 응답으로 확인해야 한다. 안 되면 신호기현황 주소를 변환하는데, 번지 주소는 필지 중심이라 교차로에서 벗어날 수 있다.
3. 1:1,000 수록 여부: 규격에는 항목이 있으나 제주 도엽의 실제 수록은 미확인이다. NGI 형식은 GDAL이 읽지 못해 직접 해석하거나 DXF판을 쓴다.
4. 외부 전송: 주소 변환 API에는 공개 시설 주소만 보낸다.
5. 도로 등급: 82.5%가 '미분류'라 등급 대신 차로수와 도로 폭을 쓴다.
6. 시점 차이: 2020(어린이보호구역), 2022(신호기), 2025~26(그 외). 자료별 기준일을 기록하고 논문 한계로 적는다.
7. 공원은 점 1개로만 제공되어 넓은 공원은 입구 위치가 아니다.

## 8. 자료 품질 기준과 실패 처리

실패는 세 단계로 나눈다.

1. 보정 가능: 규칙이나 변환을 고쳐 같은 기준으로 다시 잰다.
2. 일부 제한: 해당 선호나 지역만 빼고 진행하고 이유를 기록한다.
3. 실험 불가: 보정해도 도로 그래프가 기준을 넘지 못하거나, 세 선호 중 둘 이상을 쓸 수 없는 경우. 이때만 다른 도시(1순위 대전)로 옮긴다.

이 구분과 아래 값은 경로 실험 전에 고정한다. 옮긴 도시에도 같은 기준을 적용하고, 결과가 잘 나오는지를 보고 도시를 바꾸지 않는다. 보류 자료의 부족은 이동 사유가 아니다.

| 항목 (값은 제안) | 기준 | 못 넘으면 |
|---|---|---|
| 겹친 길 비율(제주시 시험구역, 11/9 진단과 같은 방식) | 1% 이하 | 보정, 안 되면 실험 불가 |
| 신호 교차로 자료 중 도로 교차로에 붙는 비율 | 90% 이상 | 보정, 안 되면 신호 교차로 선호 제외 |
| 서귀포시 보행신호 횡단보도 844개 중 50m 안에 신호 교차로가 있는 비율 | 70% 이상 | 보정, 안 되면 신호 교차로 선호 제외 |
| 표고점 검증 오차 중앙값(공간 분리한 점 기준) | 2m 이하 | 보정, 안 되면 경사 선호 제외 |
| 구간 길이 50·100·200m에서 경사 선호 효과의 방향 | 모두 같음 | 경사 지표 해석 제한 |
| 고도 누락 | 1% 이하 | 보정 |
| 서귀포시 표준 횡단보도 중 20m 안에 1:1,000 횡단보도가 있는 비율 (횡단보도 지표를 넣을 때만, 도엽이 있는 곳만) | 70% 이상 | 횡단보도 지표 제외 |
