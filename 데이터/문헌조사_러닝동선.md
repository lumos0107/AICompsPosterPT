# 러닝 동선 규칙의 근거 문헌 (2026-11-10 조사)

- **목적:** 러닝 동선 규칙의 근거를 찾는다. 규칙은 덜 꺾임, 단순한 고리, 달리기 좋은 길, 덜 멈춤, 서로 다른 경로, 거리 정확도다.
- **계기:** 사용자 지적. 본 실험 경로가 러닝 동선과 거리가 멀다고 봤다(측정은 `../실험/코드수정_1110/러닝규칙_측정.out`).
- **확인 수준 표시:**
  - [원문]: 원문을 읽고 문장까지 확인했다.
  - [요약]: 검색 결과 요약으로만 확인했다. 인용 전에 원문 확인이 필요하다.
